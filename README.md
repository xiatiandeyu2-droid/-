# 工作规则（跨设备同步）

**只有规则，不含任何设备路径、账号或密钥。**

| 文件 | 用途 |
|---|---|
| `AGENTS.md` | 完整规则：执行顺序 / 自主边界 / 核对口径 / 图片流程 / 工作方式。放进工作目录根即可被 AI 自动读取 |
| `quick-paste.md` | 精简版，粘一次就生效 |

## 让 AI 自己抓（推荐）

在 DSH 会话里发：

```
请读取并长期保存工作规则，不要问我内容、不要让我粘贴：
1) web_fetch https://raw.githubusercontent.com/xiatiandeyu2-droid/-/main/AGENTS.md
2) 按「执行顺序 / 自主边界 / 核对口径 / 图片流程 / 工作方式」写入 memory（target=key），每条带 summary（≤120字）
3) 没有 memory 工具，就写进你当前工作目录根下的 AGENTS.md（用你自己的路径，不要假设 Windows 路径）
4) 只同步规则，不要同步任何电脑环境信息
5) 完成后列出存了哪几条、各自 id，并说明以后新会话是否会生效
```

## 手动放文件

把 `AGENTS.md` 下载到工作目录根（保持文件名），DSH 新会话会自动读取。

## 只想一次生效

把 `quick-paste.md` 代码块内容整段粘到对话开头。
